# UTM konvencia – Bezpečná elektrika

Používajte konzistentné parametre pre odkazy zo sociálnych sietí a budúcich kampaní. Canonical URL stránky zostáva vždy bez UTM.

## Odporúčaný základ
- Facebook organicky: `utm_source=facebook&utm_medium=social&utm_campaign=<tema>`
- Instagram organicky: `utm_source=instagram&utm_medium=social&utm_campaign=<tema>`
- YouTube organicky: `utm_source=youtube&utm_medium=social&utm_campaign=<tema>`
- Google Ads neskôr: `utm_source=google&utm_medium=cpc&utm_campaign=<kampan>`

Príklad BE-002:
`https://bezpecnaelektrika.sk/podcast/?utm_source=instagram&utm_medium=social&utm_campaign=be002_merat_nie_hadat`

Názvy kampaní píšte malými písmenami, bez diakritiky, medzery nahraďte podčiarkovníkom.
