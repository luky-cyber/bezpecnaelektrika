# Bezpečná elektrika v0.6.0 — prototype A

Testovací build informačnej architektúry „Revízie na prvom mieste“.

Nie je určený na produkčné nasadenie ani GitHub Release/tag. Základom je v0.5.13.

## Cieľ testu

Po 5–10 sekundách na homepage má nový návštevník pochopiť:

- že projekt smeruje k revíziám elektrických inštalácií,
- pre aké typické objekty/situácie,
- kde zistí, kedy revíziu riešiť a ako často,
- že komerčné služby zatiaľ nie sú spustené,
- že odborná vrstva zostáva dostupná, ale nie je hlavný vstup.

## Rozsah prototypu

- service-first globálna navigácia,
- nový homepage hero,
- typické situácie,
- „Kedy revíziu riešiť“,
- „Ako často“,
- sekundárny brand blok „Merať. Dokumentovať. Vysvetľovať.“,
- zjednodušený vstup do Poradne / Glosára / Merania / Noviniek.

Stránka `/revizie/` a ostatné obsahové stránky zatiaľ nie sú kompletne redizajnované; prototyp overuje predovšetkým prvý dojem a informačnú hierarchiu homepage.
