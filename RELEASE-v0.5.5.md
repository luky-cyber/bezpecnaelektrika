# Bezpečná elektrika v0.5.5 — Poradňa & Answer Engine

## Hlavné zmeny
- Poradňa rozšírená o 8 samostatných, indexovateľných odpovedí na konkrétne otázky budúcich zákazníkov.
- Každá odpoveď používa vzor: Stručne → vysvetlenie → hranice tvrdenia → súvislosť s revíziou → súvisiace témy → metodická poznámka.
- Centrálna Poradňa funguje ako rozcestník k novým odpovediam.
- Doplnené interné prelinkovanie medzi Poradňou, Revíziami, Meraním, Glosárom a Metodikou.
- Viditeľné dátumy aktualizácie a `dateModified` na nových odpovediach.
- JSON-LD `Person` doplnený o konzervatívne `knowsAbout`; project status je zjednotený.
- FAQPage na Poradni zodpovedá viditeľnému FAQ obsahu.
- Sitemap doplnená o všetkých 8 nových URL.

## Obsahové zásady
- Žiadne fiktívne prípadové štúdie ani fiktívne merania.
- Žiadne univerzálne závery tam, kde rozhoduje konkrétna elektroinštalácia.
- Revízne služby zostávajú jasne označené ako pripravované; komerčné služby zatiaľ nie sú poskytované.
- `llms.txt` zostáva doplnkom, nie hlavným SEO/AEO mechanizmom.
